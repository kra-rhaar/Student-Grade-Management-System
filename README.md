## Description

A web-based grade management system for classrooms. Teachers can add students with their Math, Science, English, and History scores. The app automatically calculates totals, averages, and letter grades, displays everything in a table, and allows filtering by grade or minimum average. It also shows class summary statistics and lets you export all student data as a JSON file.

## Technologies Used

- HTML
- CSS
- JavaScript

## About the Project

This project is a simple grade management tool for classrooms. A teacher can enter a student's name along with their scores in four subjects (Math, Science, English, History). The system checks that the name isn't empty and that all scores fall between 0 and 100. Once added, it works out the student's total marks, their average, and assigns them a letter grade from A to F.

All students are shown together in a table, and the app also works out class-wide statistics like the class average, the highest scorer, and the lowest scorer. There's a way to narrow down the table to just a certain grade, or to only students above a chosen average. Any student can be removed with a delete button, and the whole list can be exported as a JSON file to keep or share. Data is also saved in the browser, so it's still there if the page is refreshed.
